## AI の利用ルール

AIを利用した開発では、[AGENTS.md](./AGENTS.md) に記載されたルールに従ってください。

## 班の開発ルール

班のミーティングで決め、決まった項目から書き換えてください。

| 項目                        | 内容                                                                                                                                                                                                                                                                 |
| --------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| リポジトリのリーダー        | `main` は班の組織アカウント [HealthCareFirst](https://github.com/HealthCareFirst) に置く。Branch protection はのむりんが設定済み（PR 必須、Approve 1 件以上、管理者も例外なし）                                                                                      |
| ブランチ命名規則            | `種類/内容` の形にする。種類はコミットメッセージと同じ5つ（`feat` / `fix` / `docs` / `refactor` / `chore`）。内容は英小文字とハイフンで書く（例：`feat/search`、`fix/login-error`、`docs/readme-rules`）。日本語・空白・括弧は使わない。merge 後にブランチを削除する |
| Merge 担当者                | Approve したレビュアーが merge する。作成者は自分の PR を merge しない                                                                                                                                                                                               |
| PR レビューの最低基準       | ① PR 本文の確認手順どおりに手元で動かす ② Files changed で、頼んでいないファイルや `.env` が入っていないかを見る ③ 分からない行はコメントで質問する ④ Approve のコメントに確認した結果を一言書く（例：手元で起動して確認しました）                                   |
| `.env` の安全な受け渡し方法 | GitHub（コード・Issue・PR）には載せない。キー名だけを書いた `.env.example` をリポジトリで共有し、値は Slack の DM など班内の非公開の手段で個別に渡す。公開チャンネルには貼らない。漏れたらすぐ班長と講師に連絡し、接続情報を変更する                                 |
| AI の利用ルール             | [AGENTS.md](./AGENTS.md) を参照                                                                                                                                                                                                                                      |
